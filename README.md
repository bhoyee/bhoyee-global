# Bhoyee Global Enterprise Website

Official website for Bhoyee Global Enterprise, a professional innovation-focused business offering elite training, business transformation, digital innovation and automation, and custom software and AI engineering services.

Live site: https://bhoyee-global.vercel.app

## Overview

This repository contains the public marketing website for Bhoyee Global Enterprise. The site includes company information, service pages, a contact form, custom branding, favicon, and email contact details.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Radix UI
- Lucide React
- Vercel

## Requirements

- Node.js 20 or newer
- npm 10 or newer
- pnpm via Corepack, recommended for Vercel-compatible installs

## Getting Started

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

The app will run at:

```text
http://127.0.0.1:5173
```

## Build

Create a production build:

```bash
npm run build
```

The production output is generated in:

```text
dist
```

## Deployment

The site is deployed on Vercel from the `main` branch.

Recommended Vercel settings:

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `pnpm install`
